# Screenshots

The README images show the installed application with generated demonstration
media. Each combines matching dark-theme (upper-left) and light-theme
(lower-right) window captures along a diagonal seam. The media pixels are
unchanged by the GTK theme.

The gallery capture includes the fuzzy search/status bar. The photo capture
shows the original fitted to its window before user zoom. Images contain only
the application client area, without desktop panels, personal paths or metadata.
These documentation images complement the programmatic GUI acceptance tests.
